# Piano samples

From the Salamander Grand Piano V3 by Alexander Holm, licensed under
[CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). These are the
Tone.js-hosted MP3s (https://tonejs.github.io/audio/salamander/), one every
minor third from C2 to C7, unmodified. Credited on the ii-Vs page, which plays
them through `src/lib/pianoSampler.js`.
